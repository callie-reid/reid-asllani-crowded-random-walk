# Crowding reshapes relaxation in nonlinear random walks on heterogeneous networks

Code and data accompanying the paper by Callie Reid and Malbor Asllani (Department of Mathematics, Florida State University).

**Paper:** [add link or arXiv/DOI when available]

## Overview

This repository studies a conservative nonlinear random walk on networks with finite node capacity, where the accessibility of a node with occupancy x is weighted by (1 − x)^σ. The code computes the stationary distribution, the Jacobian relaxation spectrum, and the baseline-mode Rayleigh and localized (host-node and local-star) approximations, and reproduces the figures in the paper.

## Data

The empirical networks (Table I of the paper) were symmetrized, binarized, stripped of self-loops, and reduced to their largest connected component. Sources and preprocessing details are listed in `data/README.md`. Third-party datasets keep the licenses of their original sources.
